## 🐍 Python – Automation, APIs, and The Glue of DevOps

See also: [[Linux]] | [[Kubernetes]]

Python is where everything comes together — automation, APIs, infrastructure, and data.  
In DevOps, it’s the bridge between the human and the machine.

This folder is my journey into mastering Python as a **DevOps automation language**, not as a general-purpose toy.  
Every script, every project, every line of code here ties back to real infrastructure problems.

---

## 💡 What You’ll Find Here

- **System Automation**  
  Scripts that control, monitor, or configure Linux systems.  
  From file backups to log parsing, and system health checks to service restarts.

- **API Workflows**  
  Interacting with REST APIs — AWS, Kubernetes, Docker, GitHub, and custom tools.  
  Learning to automate the cloud, one API call at a time.

- **CLI Tools**  
  Command-line utilities written in Python with `argparse` and `click`.  
  Building my own tools to manage my homelab and cloud environments efficiently.

- **Infrastructure as Code**  
  Using Python to generate configuration files, templates, and manage Terraform or Ansible workflows.

- **Monitoring & Logging**  
  Gathering metrics, writing alert scripts, and automating log analysis.

---

## ⚙️ Projects & Goals

- Create a **system monitor CLI** that reports CPU, RAM, and disk usage.  
- Build a **Kubernetes API automation tool** that deploys or scales pods from Python.  
- Write a **config backup manager** for Linux servers.  
- Automate common DevOps tasks — container cleanup, resource reports, service restarts.
